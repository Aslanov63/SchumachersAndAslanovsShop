# 🏎️ AutoFleet & Dealership Management System

> A comprehensive enterprise web solution built on **.NET** for car dealerships, fleet managers, and commercial car-park owners.

---

## 📌 Project Overview

This application is a full-featured web-based ecosystem designed to streamline inventory, sales, financial flows, and multi-user access within automotive businesses. Developed as a semester project at the **Transport and Telecommunication Institute (TSI)**, the system combines public-facing commerce tools with deep back-office management capabilities.

---

## ✨ Key Features

* **🚗 Dealership & Marketplace (Buy / Sell)**
  * Full-cycle management for buying and selling vehicles and spare parts.
  * Catalog filtering, status tracking, and inventory control.

* **👥 Multi-Accounting Support**
  * Effortless management and switching across multiple business units, dealerships, or sub-accounts within a single organization.

* **📊 Built-in CRM System**
  * Client relationship management, transaction pipelines, customer interaction histories, and lead conversion tracking.

* **💼 Accounting & Financial Engine**
  * Complete financial tracking for incoming/outgoing cash flows, deal invoicing, profit margins, and inventory asset valuation.

* **🛡️ Role-Based Access Control (RBAC)**
  * Advanced multi-role system (e.g., *Admin, moderator , userя*) with strict endpoint and UI permission mapping.

---

## 🏛️ Architecture & Tech Stack

* **Framework:** .NET (ASP.NET Core Web App)
* **Architecture:** Layered Architecture / MVC
* **Database:** Integrated **Oracle Database** (Oracle SQL) via **Entity Framework Core** (`Oracle.EntityFrameworkCore` / ODP.NET)
* **Authentication & Authorization:** .NET Identity / Role-based authorization
* **Frontend:** Razor Pages / MVC Views with Modern CSS Frameworks
